# TDU Oʻahu Map (standalone)

A single-file, offline, interactive map of Oʻahu from **Test Drive Unlimited (2006)**, built from the game's own files. Download `index.html` and open it in any browser; no internet needed.

- **Terrain:** the game's 99 Area terrain textures (11264×9216), plus a 2× close-zoom level from the game's sector layers.
- **521 locations:**
  - car/bike showrooms (stock, DLC flagged), tuners (stage prices), houses (garage, price, resale);
  - 269 races and speed/time challenges (rank needed, vehicle/brand/group, prize, medal targets, route);
  - 100 missions (client, reward, time limit, destination).
- Searchable and filterable.

The full-resolution version, with 8× terrain, animated water and aircraft, is at https://github.com/otaking111/TDUFull

Shop and house positions come from the Test Drive Wiki map, re-projected onto the game terrain. Everything else is read from the game data.
